Virtual AI Doctor: a Spring AI & MCP health assistant

An AI-powered virtual doctor built with Java, Spring Boot, Spring AI and the Model Context Protocol, where the model fetches patient context and flags emergencies through tool calls.

Overview

Virtual AI Doctor lets users describe their symptoms in Hindi or English and get medical guidance in the same language. It is a learning and portfolio project and does not replace a real doctor.

The design change that mattered

The first version built one large prompt for every message: instructions, the full health profile, the conversation so far and the new symptoms. Every request carried data it often didn't need, prompts kept growing, and detecting emergencies meant parsing a severity tag out of plain text.

I re-architected the AI layer around Spring AI's Model Context Protocol (MCP) server/client integration, built on the official MCP Java SDK, so the model can call tools only when it needs them:

  • getPatientProfile fetches age, blood group, allergies and history on demand.
  • flagHighSeverity is called by the model itself when it judges a consultation to be an emergency, which replaces fragile text parsing.

Features

  • AI symptom analysis with Groq (LLaMA 3.1) through Spring AI
  • Automatic Hindi / English detection and replies
  • Persistent multi-turn memory with Spring AI ChatMemory (JDBC, MySQL)
  • JWT-secured signup, login and APIs
  • Email alerts and downloadable PDF reports for high-severity cases
  • Nearby pharmacy finder using OpenStreetMap and the Overpass API
  • Consultation history, health profile, dark / light mode
